# I2C

- Multi-master, multi-slave, packet-switched, single-ended serial communication

---

## Features

- 2-wire interface (SDA and SCL)
- Each device has a unique address
- Synchronous
- Simple and low-cost

---

## Interface

| Line | Full Name | Description |
|------|-----------|-------------|
| **SDA** | Serial Data | Carries data being transferred (bidirectional) |
| **SCL** | Serial Clock | Carries the clock signal generated by the master |

---

## Communication Process

1. **Start Condition** — Master pulls SDA low while SCL remains high.
2. **Address Frame** — Master sends the address of the target device followed by the read/write bit (`0` = write, `1` = read).
3. **Acknowledge Bit** — The slave responds with an ACK bit by pulling the SDA line low.
4. **Data Frames** — Data is transferred in 8-bit blocks, each followed by an ACK bit.
5. **Stop Condition** — Master releases (pulls high) the SDA line while SCL is high.

---

## Registers

### 1. I2C_CR1 (Control Register 1)

| Bit | Name | Description |
|-----|------|-------------|
| 15 | SWRST | Software Reset<br>`0` = Not under reset<br>`1` = Under reset |
| 11 | POS | Acknowledge/PEC Position<br>`0` = ACK bit controls the (N)ACK of the current byte being received<br>`1` = ACK bit controls the (N)ACK of the next byte which is received |
| 10 | ACK | Acknowledge Enable<br>`0` = No acknowledge returned<br>`1` = Acknowledge returned after a byte is received |
| 9 | STOP | Stop Generation<br>**In Controller mode:**<br>`0` = No Stop generation<br>`1` = Stop generation after the current byte transfer or after the current Start condition is sent<br>**In Target mode:**<br>`0` = No Stop generation<br>`1` = Release the SCL and SDA lines after the current byte transfer |
| 8 | START | Start Generation<br>**In Controller mode:**<br>`0` = No Start generation<br>`1` = Repeated start generation<br>**In Target mode:**<br>`0` = No Start generation<br>`1` = Start generation when the bus is free |
| 0 | PE | Peripheral Enable<br>`0` = Peripheral disable<br>`1` = Peripheral enable |

```c
// Enable I2C peripheral and enable ACK
I2C1->CR1 |= (1 << 0);   // PE  - enable peripheral
I2C1->CR1 |= (1 << 10);  // ACK - acknowledge returned after receiving a byte

// Generate a Start condition
I2C1->CR1 |= (1 << 8);   // START - generate Start condition
```

---

### 2. I2C_CR2 (Control Register 2)

| Bit | Name | Description |
|-----|------|-------------|
| 11 | DMAEN | DMA Enable<br>`0` = DMA disabled<br>`1` = DMA enabled |
| 5:0 | FREQ | Peripheral Clock Frequency<br>Accepts values from `0b000010` (2 MHz) to `0b110010` (50 MHz) |

```c
// Set peripheral frequency to 16 MHz and enable DMA
I2C1->CR2 &= ~0x3F;       // Clear FREQ bits (bits 5:0)
I2C1->CR2 |= 16;          // Set FREQ to 16 (0x10) to match 16 MHz APB clock
I2C1->CR2 |= (1 << 11);   // DMAEN - enable DMA
```

---

### 3. I2C_CCR (Clock Control Register)

| Bit | Name | Description |
|-----|------|-------------|
| 15 | F/S | I2C Mode Selection<br>`0` = Sm (Standard mode)<br>`1` = Fm (Fast mode) |
| 14 | DUTY | Fast Mode Duty Cycle (only applicable in Fast mode)<br>`0` = t_low/t_high = 2<br>`1` = t_low/t_high = 16/9 |
| 11:0 | CCR | Clock Control Value<br>Used to set clock control value |

```c
// Configure I2C Clock Control: Standard Mode (100 kHz) with a 16 MHz peripheral clock
// In Standard mode, CCR = T_high / T_PCLK = (T_SCL / 2) / T_PCLK
// For 100 kHz SCL, T_SCL = 10 µs. T_high = 5 µs.
// With 16 MHz clock, T_PCLK = 62.5 ns.
// CCR = 5 µs / 62.5 ns = 80
I2C1->CCR &= ~(1 << 15);  // Set F/S = 0 (Standard mode)
I2C1->CCR = 80;           // Set CCR value to 80
```

---

### 4. I2C_TRISE (Rise Time Register)

| Bit | Name | Description |
|-----|------|-------------|
| 5:0 | TRISE | Maximum rise time for SDA and SCL signals |

```c
// Configure TRISE: For Standard mode (max rise time 1000 ns), with a 16 MHz clock
// TRISE = (Max Rise Time / T_PCLK) + 1
// TRISE = (1000 ns / 62.5 ns) + 1 = 16 + 1 = 17
I2C1->TRISE = 17;
```

---

### 5. I2C_DR (Data Register)

| Bit | Name | Description |
|-----|------|-------------|
| 7:0 | DR | Data Register (used for transmitting and receiving data) |

```c
// Transmit a byte
while (!(I2C1->SR1 & (1 << 7)));  // Wait for TxE (Data register empty) in SR1
I2C1->DR = 0xA5;                  // Write data to DR

// Receive a byte
while (!(I2C1->SR1 & (1 << 6)));  // Wait for RxNE (Data register not empty) in SR1
uint8_t received_data = I2C1->DR; // Read data from DR
```
