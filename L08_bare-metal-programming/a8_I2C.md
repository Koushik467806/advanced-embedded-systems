I2C



Multi master, multi slave, packet switched, single-ended serial communication



Features

2 wire interface (SDA and SCL)

Each device has unique address

synchronous

simple and low-cost



Interface

SDA: Carries data being transferred (bi-directional)

SCL: Carries CLK signal generated by master



Communication Process

Start condition: Pulls SDA to low while SCL is high

Address frame: Master send address of target device then read/write bit (0: write, 1: read)

Acknowledge bit: slave responds with ACK bit by pulling SDA line to low

Data Frames: Data transferred in 8-bits, followed by an ACK bit

Stop Condition: Pulls SDA line high when SCL line is high



Registers

1. I2C\_CR1

Bit 0 PE: 0: peripheral disable

1: peripheral enable

Bit 8 START

In Controller mode:

0: No Start generation

1: Repeated start generation

In Target mode:

0: No Start generation

1: Start generation when the bus is free

Bit 9 STOP

In Controller mode:

0: No Stop generation.

1: Stop generation after the current byte transfer or after the current Start condition is sent.

In Target mode:

0: No Stop generation.

1: Release the SCL and SDA lines after the current byte transfer. 

Bit 10 ACK: 0: No acknowledge returned

1: Acknowledge returned after a byte is received

Bit 11 POS:

0: ACK bit controls the (N)ACK of the current byte being received

1: ACK bit controls the (N)ACK of the next byte which is received

Bit 15 SWRST:

0: Not under reset

1: Under reset



2\. I2C\_CR2

Bit 11 DMAEN

0: DMA disabled

1: DMA enabled

Bits 5:0 FREQ:

from 0b000010 to 0b110010 MHz



3\. I2C\_CCR

Bits 11:0 CCR: Used to set clock control value

Bit 14 DUTY: 0: Fm mode t\_low/t\_high = 2

1: Fm mode t\_low/t\_high = 16/9

Bit 15 F/S: 0: Sm mode

1: Fm mode



Sm: Standard mode

Fm: Fast mode



4\. I2C\_TRISE

Bits 5:0 TRISE: Maximum rise time for SDA and SCL signals



5\. I2C\_DR

Bits 7:0: Used for transmistting and receiving data
