**Command Line Interface (CLI)**

1. Access through terminal
2. Linux is popular
3. For editing, we can use notepad++, vim or sublime text
4. For building, we use GNU toolchain
5. For installation and debugging, it depends on architecture (We can use GNU debugger)



**Integrated Development Environment (IDE)**

1. More user-friendly
2. We can do editing, building installation and debugging in the same software
