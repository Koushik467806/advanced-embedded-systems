# Single vs Double Precision

| Property            | Single Precision | Double Precision |
|---------------------|-----------------|-----------------|
| **C Data Type**     | `float` — `%f` / `%e` (scientific) | `double` — `%lf` / `%le` (scientific) |
| **Total Bits**      | 32 bits         | 64 bits         |
| **Significant Bits**| 23 bits         | 52 bits         |
| **Exponent Bits**   | 8 bits          | 11 bits         |
| **Sign Bit**        | 1 bit           | 1 bit           |
