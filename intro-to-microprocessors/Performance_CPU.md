**Clock Speed:** Number of pulses a clock produces each second (also number of instruction cycles it triggers per second)



**Burst Time:** The amount of CPU time the process required to complete its execution



**Cache:** Temporary storage location which is very fast at retrieving data

**L1 Cache:** Closest to the CPU, smallest and the fastest

**L2 Cache:** Between **L1** and **L3** in terms of size, location and cost

**L3 Cache:** Farther from CPU, largest but slower



**Scheduling**

1. Non-Preemptive Scheduling: The current task will be finished first and then move on to the next task even if the next task is more important
2. Preemptive Scheduling: The current task will be stopped to finish the next task if it is more important than the current task



**Pipelining**

Pipeline system starts the fetch of next instruction just after the current instruction's fetch is completed and moved on to the decoding section which makes sure every core of the processor is being constantly used
