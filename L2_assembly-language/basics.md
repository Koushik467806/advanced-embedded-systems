**Special Registers**

1. sp (Stack Pointer): Tells us next available piece of memory
2. lr (Link Register): Stores location of where the function should return to
3. pc (Program Counter): Location of next instruction to execute
4. cpsr: Stores information about our program (tells special information about our program)
5. spsr: Preserves state of CPU if there is any error
6. r7: Stores information about system calls
